# 英语学习助手

“英语学习助手”是一个适合英语初学者的简单网页应用。它参考了背单词软件常见的学习逻辑：看单词、理解意思、判断是否认识、把不会的单词加入复习列表，并提供一个简单的测试模式。

本项目没有照抄任何现有产品的界面、名字、图片、素材或品牌设计。第一版只使用 HTML、CSS 和 JavaScript，不使用数据库、不做登录功能，也不需要复杂后端。

## 第一版功能

- 首页显示应用名称：“英语学习助手”。
- 显示单词卡片，包含：
  - 英文单词
  - 中文意思
  - 英文例句
  - 例句中文解释
- 提供“认识”和“不认识”两个按钮。
- 点击“不认识”后，当前单词会加入复习列表。
- 点击“下一个单词”后，切换到下一个单词。
- 提供“测试模式”：显示中文意思，让用户输入英文单词。
- 显示学习进度，例如“已学习 3 / 20”。
- 页面风格简洁，适合手机和电脑浏览。
- 代码中包含中文注释，方便初学者阅读。

## 文件说明

```text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

### `index.html`

负责网页结构，也就是页面上有什么内容。

它包含：

- 应用标题
- 学习进度
- 学习模式和测试模式按钮
- 单词卡片
- “认识”“不认识”“下一个单词”按钮
- 测试模式输入框
- 复习列表

### `style.css`

负责网页样式，也就是页面看起来是什么样。

它包含：

- 页面整体布局
- 卡片样式
- 按钮样式
- 输入框样式
- 复习列表样式
- 手机屏幕适配

### `script.js`

负责网页交互逻辑，也就是点击按钮后会发生什么。

它包含：

- 20 个基础英语单词数据
- 当前单词序号
- 复习列表数据
- 显示当前单词
- 切换下一个单词
- 把不认识的单词加入复习列表
- 测试模式答案检查
- 学习模式和测试模式切换

### `README.md`

负责说明项目是什么、如何使用、每个文件的作用，以及后续可以如何升级。

## 如何打开使用

方法一：直接打开

1. 下载或克隆本项目。
2. 在文件夹中找到 `index.html`。
3. 用浏览器打开 `index.html`。
4. 开始学习单词。

方法二：使用本地服务器

如果你电脑上安装了 Python，也可以在项目目录运行：

```bash
python3 -m http.server 4173
```

然后在浏览器打开：

```text
http://127.0.0.1:4173
```

## 使用建议

1. 先在“学习模式”中看单词、意思和例句。
2. 如果认识这个单词，点击“认识”。
3. 如果不认识这个单词，点击“不认识”，它会加入复习列表。
4. 点击“下一个单词”可以主动切换到下一个。
5. 切换到“测试模式”后，根据中文意思输入英文单词。
6. 如果测试答错，单词也会加入复习列表。

## 后续可以怎么升级

后续可以逐步增加这些功能：

1. **隐藏中文释义**
   - 先只显示英文单词，点击按钮后再显示中文意思。

2. **复习列表单独练习**
   - 只练习用户不认识的单词。

3. **本地保存学习记录**
   - 使用 `localStorage` 保存复习列表和学习进度。

4. **单词分类**
   - 例如：食物、学校、家庭、旅行等分类。

5. **发音功能**
   - 使用浏览器语音 API 播放英文单词发音。

6. **更完整的测试模式**
   - 统计答对和答错数量。
   - 学完一轮后显示测试总结。

7. **更好的移动端体验**
   - 优化按钮大小、卡片间距和输入框体验。

## 第一版暂时不做什么

为了保持简单，第一版暂时不做：

- 用户登录
- 数据库
- 后端接口
- 云端同步
- 复杂动画
- 排行榜
- 付费功能
- 手机 App
